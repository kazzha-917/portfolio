StyleGAN3 생성 얼굴 이미지 탐지

StyleGAN3로 생성한 얼굴 이미지와 실제 얼굴 이미지를 구분하는 연구를 수행했습니다. 기존 얼굴 탐지 방식인 MTCNN·DeepFace가 생성 이미지의 얼굴 영역을 안정적으로 검출하지 못하자, YOLOv5를 활용해 얼굴 ROI를 직접 라벨링·탐지하는 방식으로 전환했습니다. 이후 random crop을 결합해 학습 데이터를 보강하고, XceptionNet 기반 분류 모델로 실제·생성 이미지를 분류해 약 92.67%의 테스트 정확도를 확인했습니다.
